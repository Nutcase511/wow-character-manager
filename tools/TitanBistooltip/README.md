TitanBistooltip 是一款适用于《魔兽世界》泰坦重铸时光服的插件，主要用于显示职业和专精的最优装备(BIS)排名、附魔、宝石建议，以及增强鼠标BIS提示的功能。

对于新手玩家，TitanBistooltip能帮助快速了解装备优先级，避免被某些人误导。

TitanBistooltip支持三种语言：中文简体、繁体以及英文。

快跑兄弟持续在完善各个阶段！

主要功能：
1. BIS装备面板：显示各职业各专精在不同阶段的推荐装备、附魔、宝石等。
2. 毕业装备面板：显示各职业各专精的在不同阶段的毕业装备。
3. 装备排名系统：在查看装备或者鼠标悬停装备上时显示其在BIS列表中的排名。
4. 物品复制功能：支持右键点击装备、宝石、附魔名称复制到剪贴板。

数据库：快跑兄弟的本地数据库。
当前的数据统计：
- 总职业数：10个，包含死亡骑士、圣骑士、德鲁伊、猎人、牧师、法师、战士、潜行者、术士、萨满。
- 总专精数：32个（2026.1.27新增-盗贼敏锐专精；2026.3.18新增-死亡骑士鲜血输出专精）。
- 总装备数据：约1900件。
- 支持阶段：PR、P1、P2、P3、P4-P11

打开BIS装备面板：
- 使用命令/bis、/titanbistooltip 打开 BIS面板。
- 或点击小地图T图标打开面板。

面板选项：
- 过滤专精：可以选择只显示特定专精的BIS排名。
- 过滤职业：可以选择特定职业的BIS装备提示。
- 过滤阶段：可以选择特定阶段的鼠标BIS提示。
- 工具提示位置：设置装备排名信息在工具提示的方位。
- 高亮天赋：可以高亮显示特定天赋的装备排名。

已知问题：
- 在某些情况下，装备排名可能会显示不准确，这可能是由于数据库更新不及时导致的。
- 插件在游戏版本数据更新后可能需要进行调整，以确保数据准确性。

- 新增：配置存储方式选项，让用户可以自己选择配置是账号通用还是角色独立。默认是账号通用，可以随时切换，切换后会提示重载界面。
- 这个新增我解释一下：本身没有多少设置为什么要添加这个新增的选项呢？因为太多人说目前的角色独立设置对于号多的人每个角色都要重新配置界面非常麻烦，而且时光服这种玩家非常多。所以我认真思考后认为确实有必要为这部分朋友考虑一下。于是重新遍历了所有代码，修改了259处，添加了这个设置选项，其中一个账号通用设置是让所有配置设置从char级别改到账号级别（global），所有账号共享同一套设置，即：不论切换到哪个角色，设置都会保持一致。这样就可以自己决定用哪种方式了。但是如何再切换角色独立呢？然后我用到了一个超级聪明的实现，完全没有再改那259处调用，我把db.global变成了一个代理表，根据用户选择的存储方式，自动把数据存到正确的位置。
  - 选"账号通用"：数据存在 db.global 顶层
  - 选"角色独立"：数据存在 db.global.characters[角色名] 下。
  - 当切换时自动迁移 ：第一次切换到角色独立时，会自动把当前账号的配置复制一份给该角色。
  - 即时生效 ：在设置界面切换存储方式后，立即生效（会自动重新初始化代理）
这样就完成啦，我对于这个选项其实挺满意的，这样就可以根据自己的需求选择用哪种方式了。
