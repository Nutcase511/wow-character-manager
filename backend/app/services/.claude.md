# Services - 业务逻辑层

## 概述
处理复杂的业务逻辑，特别是与外部API的集成。

## 核心服务

### BlizzardAPIService (暴雪API服务)
负责与暴雪游戏数据API的交互。

#### 主要功能
- **OAuth认证管理**
  - 自动获取和刷新访问令牌
  - 令牌过期前自动刷新
  - 安全的凭证存储

- **装备数据获取**
  - `get_item_icon(item_id)` - 获取装备图标URL
  - `get_item_details(item_id)` - 获取完整装备信息
  - 自动解析装备属性（力量、敏捷、暴击等）

- **副本数据获取**
  - `get_journal_instance(instance_id)` - 获取副本详细信息
  - 包含副本描述、地图、难度模式等

- **Boss数据获取**
  - `get_journal_encounter(encounter_id)` - 获取Boss详细信息
  - 包含Boss描述、所属副本、分类等

- **服务器数据获取** (新增)
  - `get_realms(classic=False)` - 获取服务器列表
  - `get_realm(realm_slug, classic=False)` - 获取指定服务器信息
  - 支持怀旧服和正式服服务器
  - 支持区域过滤

#### 数据处理
- **属性映射**: 将英文属性名映射为中文
  - STRENGTH → 力量
  - AGILITY → 敏捷
  - INTELLECT → 智力
  - CRITICAL_STRIKE → 暴击
  - HASTE → 急速
  - 等等...

- **错误处理**: 优雅处理API错误和超时
- **缓存**: 令牌自动缓存，减少API调用

#### 配置要求
```env
BLIZZARD_CLIENT_ID=你的客户端ID
BLIZZARD_CLIENT_SECRET=你的客户端密钥
BLIZZARD_REGION=cn  # 或 us/eu/kr/tw
```

#### 使用示例
```python
from app.services.blizzard_api import blizzard_api

# 获取装备详情
item = await blizzard_api.get_item_details(12345)
print(item['name'])  # 装备名称
print(item['stats'])  # 装备属性

# 获取副本信息
dungeon = await blizzard_api.get_journal_instance(1234)
print(dungeon['name'])  # 副本名称
print(dungeon['modes'])  # 难度模式
```

## 服务设计原则

### 单一职责
- 每个服务专注于特定领域
- BlizzardAPIService只处理暴雪API相关逻辑

### 错误处理
- 所有服务方法都有适当的错误处理
- 返回None或抛出有意义的异常
- 记录详细的错误日志

### 异步设计
- 所有I/O操作都是异步的
- 使用async/await语法
- 不阻塞主线程

### 可测试性
- 服务逻辑与外部依赖分离
- 可以轻松进行单元测试
- 支持依赖注入

## 扩展指南

### 添加新服务
1. 创建新的服务文件
2. 实现服务类和必要的方法
3. 添加适当的错误处理
4. 在API层中调用服务
5. 编写单元测试

### 服务最佳实践
- 使用依赖注入而不是直接实例化
- 在__init__.py中导出服务实例
- 为所有公共方法添加文档字符串
- 处理所有可能的异常情况

## 计划中的服务
- **CacheService** - 缓存管理，减少数据库和API调用
- **NotificationService** - 通知服务，装备获取提醒
- **StatisticsService** - 统计服务，生成各种报表
- **ExportService** - 导出服务，支持导出为Excel/JSON
