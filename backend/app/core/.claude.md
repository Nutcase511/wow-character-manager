# Core - 核心基础设施

## 概述
提供应用的核心基础设施，包括配置管理、数据库连接等。

## 模块说明
- **config.py** - 应用配置管理，使用pydantic-settings
- **database.py** - MongoDB异步连接管理

## 配置管理 (config.py)
### 环境变量
- **MongoDB配置**:
  - `MONGODB_URL` - MongoDB连接字符串
  - `DATABASE_NAME` - 数据库名称

- **暴雪API配置**:
  - `BLIZZARD_CLIENT_ID` - 暴雪API客户端ID
  - `BLIZZARD_CLIENT_SECRET` - 暴雪API客户端密钥
  - `BLIZZARD_REGION` - 区域设置 (us/eu/kr/tw/cn)

- **应用配置**:
  - `APP_NAME` - 应用名称
  - `APP_VERSION` - 应用版本
  - `DEBUG` - 调试模式

- **CORS配置**:
  - `FRONTEND_URL` - 前端URL

### 使用方式
```python
from app.core.config import settings

db_url = settings.MONGODB_URL
api_key = settings.BLIZZARD_CLIENT_ID
```

## 数据库管理 (database.py)
### 功能
- 异步MongoDB连接池管理
- 应用启动时自动连接
- 应用关闭时自动断开
- 提供数据库实例访问

### 使用方式
```python
from app.core.database import db

# 获取数据库实例
database = db.get_database()
collection = database["characters"]

# 执行查询
result = await collection.find_one({"_id": object_id})
```

## 生命周期管理
- **startup**: 通过FastAPI的startup事件连接数据库
- **shutdown**: 通过FastAPI的shutdown事件关闭连接

## 错误处理
- 连接失败会记录日志
- 配置验证失败会抛出异常
- 所有操作都有适当的错误处理

## 扩展性
- 可以轻松添加其他核心功能（缓存、消息队列等）
- 配置系统支持添加新的环境变量
- 数据库连接支持连接池配置
