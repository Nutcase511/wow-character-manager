# Schemas - 数据验证层

## 概述
定义API请求和响应的数据验证模式，使用Pydantic进行数据验证。

## 模式类型
### 请求模式 (Create)
- 用于接收客户端数据
- 进行数据验证和转换
- 不包含数据库字段如_id

### 响应模式 (Response)
- 用于返回数据给客户端
- 包含所有必要字段
- 支持ORM模式转换

## 核心模式

### 角色相关
#### CharacterCreate
```python
- name: str              # 必需
- realm: str             # 必需
- wow_class: WoWClass    # 必需，枚举类型
- spec: Optional[str]    # 可选
- level: int             # 默认70
- faction: str           # 默认"alliance"
```

#### CharacterResponse
- 包含所有Character字段
- 包含_id, created_at, updated_at
- 支持从ORM对象转换

### 装备相关
#### ItemCreate
```python
- item_id: int                    # 必需
- name: str                       # 必需
- quality: ItemQuality            # 必需，枚举类型
- item_level: int                 # 必需
- slot: Optional[str]             # 可选
- stats: Dict[str, int]           # 默认空字典
- icon_url: Optional[str]         # 可选
```

### 副本相关
#### DungeonCreate
```python
- dungeon_id: int              # 必需
- name: str                    # 必需
- description: Optional[str]   # 可选
- map_name: Optional[str]      # 可选
- minimum_level: int           # 默认70
- modes: List[str]             # 默认空列表
- icon_url: Optional[str]      # 可选
```

### Boss相关
#### BossCreate
```python
- boss_id: int                 # 必需
- name: str                    # 必需
- description: Optional[str]   # 可选
- dungeon_id: int              # 必需
- dungeon_name: str            # 必需
- category: Optional[str]      # 可选
- icon_url: Optional[str]      # 可选
```

### 装备需求相关
#### ItemNeedCreate
```python
- character_id: str            # 必需
- item_id: int                 # 必需
- item_name: str               # 必需
- boss_id: Optional[int]       # 可选
- boss_name: Optional[str]     # 可选
- dungeon_name: Optional[str]  # 可选
- priority: int                # 默认1，范围1-5
- obtained: bool               # 默认False
- notes: Optional[str]         # 可选
```

## 枚举类型

### WoWClass (职业枚举)
```python
WARRIOR, PALADIN, HUNTER, ROGUE, PRIEST,
DEATH_KNIGHT, SHAMAN, MAGE, WARLOCK,
MONK, DRUID, DEMON_HUNTER, EVOKER
```

### ItemQuality (装备品质枚举)
```python
POOR, COMMON, UNCOMMON, RARE, EPIC, LEGENDARY
```

## 验证规则
- **必需字段**: 使用Field(..., description="描述")
- **默认值**: 使用Field(default=值)
- **范围验证**: 使用Field(min=最小值, max=最大值)
- **枚举验证**: 使用枚举类型

## 扩展指南
添加新模式时：
1. 创建Create模式用于请求
2. 创建Response模式用于响应
3. 添加适当的验证规则
4. 使用枚举类型限制取值范围
5. 添加字段描述信息
