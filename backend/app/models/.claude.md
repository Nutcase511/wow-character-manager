# Models - 数据模型层

## 概述
定义MongoDB文档结构，所有模型继承自MongoBaseModel。

## 基础模型
### MongoBaseModel
- 提供ObjectId支持
- 自动生成_id字段
- 支持JSON序列化

## 数据模型
### Character (角色模型)
```python
- name: str              # 角色名称
- realm: str             # 服务器名称
- wow_class: str         # 职业
- spec: Optional[str]    # 专精
- level: int             # 等级
- faction: str           # 阵营
- created_at: datetime   # 创建时间
- updated_at: datetime   # 更新时间
```

### Item (装备模型)
```python
- item_id: int                    # 装备ID
- name: str                       # 装备名称
- quality: str                    # 品质
- item_level: int                 # 装备等级
- slot: Optional[str]             # 装备部位
- stats: Dict[str, int]           # 属性字典
- icon_url: Optional[str]         # 图标URL
- created_at: datetime            # 创建时间
```

### Dungeon (副本模型)
```python
- dungeon_id: int              # 副本ID
- name: str                    # 副本名称
- description: Optional[str]   # 描述
- map_name: Optional[str]      # 地图名称
- minimum_level: int           # 最低等级
- modes: List[str]             # 难度模式
- icon_url: Optional[str]      # 图标URL
- created_at: datetime         # 创建时间
```

### Boss (Boss模型)
```python
- boss_id: int                 # Boss ID
- name: str                    # Boss名称
- description: Optional[str]   # 描述
- dungeon_id: int              # 所属副本ID
- dungeon_name: str            # 所属副本名称
- category: Optional[str]      # 分类
- icon_url: Optional[str]      # 图标URL
- created_at: datetime         # 创建时间
```

### ItemNeed (装备需求模型)
```python
- character_id: str            # 角色ID
- item_id: int                 # 装备ID
- item_name: str               # 装备名称
- boss_id: Optional[int]       # Boss ID
- boss_name: Optional[str]     # Boss名称
- dungeon_name: Optional[str]  # 副本名称
- priority: int                # 优先级(1-5)
- obtained: bool               # 是否已获取
- notes: Optional[str]         # 备注
- created_at: datetime         # 创建时间
- updated_at: datetime         # 更新时间
```

### Progress (进度模型)
```python
- character_id: str            # 角色ID
- dungeon_id: int              # 副本ID
- dungeon_name: str            # 副本名称
- difficulty: str              # 难度
- bosses_killed: List[int]     # 已击杀Boss列表
- last_updated: Optional[datetime]  # 最后更新时间
- created_at: datetime         # 创建时间
```

## 设计原则
- **类型安全**: 使用Pydantic进行类型验证
- **默认值**: 为字段提供合理的默认值
- **可选字段**: 合理使用Optional类型
- **时间戳**: 自动记录创建和更新时间

## 扩展指南
添加新模型时：
1. 继承MongoBaseModel
2. 使用适当的字段类型
3. 添加必要的默认值
4. 在schemas中创建对应的模式
5. 在API中创建对应的端点

## 索引建议
- 为常用查询字段添加索引
- character_id, item_id等外键字段
- 时间字段用于范围查询
