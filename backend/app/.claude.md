# App - 应用核心模块

## 概述
包含后端应用的所有核心模块，采用分层架构设计。

## 模块说明
- **api/** - API路由层，处理HTTP请求和响应
- **core/** - 核心基础设施，数据库连接和配置
- **models/** - 数据模型层，定义MongoDB文档结构
- **schemas/** - 数据验证层，Pydantic模式定义
- **services/** - 业务逻辑层，处理复杂业务操作
- **utils/** - 工具函数层，通用辅助函数

## 设计模式
- **分层架构**: API → Services → Models
- **依赖注入**: FastAPI的依赖注入系统
- **数据验证**: Pydantic模式验证请求数据
- **异步处理**: 全面使用async/await

## 导入规范
```python
# 相对导入
from app.core.config import settings
from app.models.models import Character
from app.schemas.schemas import CharacterCreate
```

## 开发规范
- API路由使用fastapi.APIRouter
- 数据模型继承MongoBaseModel
- 请求/响应模式使用Pydantic BaseModel
- 服务层处理业务逻辑，API层只处理HTTP相关逻辑
