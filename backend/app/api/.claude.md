# API - 路由层

## 概述
定义所有RESTful API端点，处理HTTP请求和响应。

## 路由模块
- **characters.py** - 角色管理API (CRUD操作)
- **item_needs.py** - 装备需求API (需求管理、进度追踪)
- **dungeons.py** - 副本管理API (包括暴雪API同步)
- **bosses.py** - Boss管理API (包括暴雪API同步)
- **realms.py** - 服务器管理API (从暴雪API获取服务器列表)

## API设计规范
- **RESTful设计**: 遵循REST架构风格
- **统一响应格式**: 使用Pydantic响应模式
- **错误处理**: 统一使用HTTPException
- **CORS支持**: 已配置跨域访问

## 通用端点模式
```python
# 标准CRUD操作
GET    /api/resource          # 获取列表
GET    /api/resource/{id}     # 获取单个资源
POST   /api/resource          # 创建资源
PUT    /api/resource/{id}     # 更新资源
DELETE /api/resource/{id}     # 删除资源

# 特殊操作
POST   /api/resource/sync/{id}  # 从暴雪API同步
PATCH  /api/resource/{id}/action  # 特殊动作
```

## 服务器API (realms.py)

### 端点列表
```python
GET    /api/realms                    # 获取服务器列表
GET    /api/realms/{realm_slug}       # 获取指定服务器信息
GET    /api/realms/classic/list      # 获取怀旧服服务器列表
GET    /api/realms/retail/list       # 获取正式服服务器列表
```

### 查询参数
- **classic**: boolean - 是否获取怀旧服服务器（默认false）
- **region**: string - 服务器区域过滤（us, eu, kr, tw, cn）

### 响应格式
```json
{
  "id": 1,
  "name": "艾泽拉斯",
  "slug": "azerite",
  "category": "classic",
  "locale": "zhCN",
  "timezone": "Asia/Shanghai",
  "is_tournament": false,
  "region": "cn"
}
```

### 使用场景
- **怀旧服时光服**: 使用 `/api/realms/classic/list` 获取怀旧服服务器
- **正式服**: 使用 `/api/realms/retail/list` 获取正式服服务器
- **动态选择**: 使用 `/api/realms?classic=true` 动态切换服务器类型
