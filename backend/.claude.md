# Backend - 魔兽世界角色管理系统后端

## 概述
这是魔兽世界角色管理系统的后端服务，基于 FastAPI 框架构建，提供 RESTful API 接口。

## 技术栈
- **框架**: FastAPI 0.136.1
- **数据库**: MongoDB (使用 Motor 异步驱动)
- **API集成**: 暴雪游戏数据API
- **认证**: JWT (python-jose)
- **数据验证**: Pydantic 2.13.3

## 核心功能
- 角色管理 API
- 装备需求追踪 API
- 副本管理 API
- Boss管理 API
- 暴雪API数据同步服务

## 项目结构
```
backend/
├── app/
│   ├── api/          # API路由定义
│   ├── core/         # 核心配置（数据库、设置）
│   ├── models/       # MongoDB数据模型
│   ├── schemas/      # Pydantic请求/响应模式
│   ├── services/     # 业务逻辑层
│   └── utils/        # 工具函数
├── main.py           # 应用入口
├── requirements.txt  # Python依赖
└── .env.example      # 环境变量模板
```

## 环境配置
- 必需配置：MongoDB连接字符串
- 可选配置：暴雪API凭证（用于同步游戏数据）

## 启动方式
```bash
# 激活虚拟环境
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate     # Windows

# 启动开发服务器
python -m uvicorn main:app --reload
```

## API文档
启动后访问：http://localhost:8000/docs

## 数据库集合
- `characters` - 角色信息
- `dungeons` - 副本信息
- `bosses` - Boss信息
- `items` - 装备信息
- `item_needs` - 装备需求
- `raid_progress` - 副本进度

## 开发注意事项
- 所有API路由都有CORS支持
- 使用异步IO处理数据库操作
- 集成暴雪API时需要处理速率限制
- 错误处理使用HTTPException
