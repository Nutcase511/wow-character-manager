# Frontend - 魔兽世界角色管理系统前端

## 概述
基于Vue 3 + TypeScript + Element Plus构建的现代化前端应用。

## 技术栈
- **框架**: Vue 3.3.4 (Composition API)
- **语言**: TypeScript 5.2.2
- **构建工具**: Vite 5.0.0
- **UI组件**: Element Plus 2.4.2
- **状态管理**: Pinia 2.1.7
- **路由**: Vue Router 4.2.5
- **HTTP客户端**: Axios 1.6.0
- **图标**: @element-plus/icons-vue 2.1.0

## 核心特性
- 🎨 现代化UI设计，响应式布局
- 🔄 实时数据同步，自动更新
- 🌍 完整的TypeScript类型支持
- 📱 移动端友好的响应式设计
- 🎯 直观的用户交互体验

## 项目结构
```
frontend/
├── src/
│   ├── api/           # API调用层
│   ├── assets/        # 静态资源
│   ├── components/    # 可复用组件
│   ├── router/        # 路由配置
│   ├── stores/        # Pinia状态管理
│   ├── types/         # TypeScript类型定义
│   ├── views/         # 页面组件
│   ├── App.vue        # 根组件
│   └── main.ts        # 应用入口
├── public/            # 公共静态资源
├── index.html         # HTML模板
├── vite.config.ts     # Vite配置
├── tsconfig.json      # TypeScript配置
└── package.json       # 依赖管理
```

## 开发命令
```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览生产构建
npm run preview
```

## 配置说明
- **开发服务器**: http://localhost:5173
- **API代理**: /api/* 代理到 http://localhost:8000
- **环境变量**: .env 文件配置

## 页面路由
- `/` - 首页（重定向到角色管理）
- `/characters` - 角色管理
- `/characters/:id` - 角色详情
- `/dungeons` - 副本管理
- `/bosses` - Boss管理
- `/item-needs` - 装备需求管理

## 状态管理
- **characterStore** - 角色状态管理
- **itemNeedStore** - 装备需求状态管理
