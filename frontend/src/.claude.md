# Src - 源代码目录

## 概述
包含前端应用的所有源代码，采用模块化架构设计。

## 目录结构
```
src/
├── api/           # API调用封装
├── assets/        # 静态资源（图片、样式等）
├── components/    # 可复用组件
├── router/        # 路由配置
├── stores/        # Pinia状态管理
├── types/         # TypeScript类型定义
├── views/         # 页面组件
├── App.vue        # 根组件
└── main.ts        # 应用入口
```

## 模块职责
- **api/** - 封装所有HTTP请求，统一API调用
- **components/** - 可复用的UI组件
- **router/** - 应用路由配置和导航守卫
- **stores/** - 全局状态管理
- **types/** - TypeScript类型定义和接口
- **views/** - 页面级组件，对应路由

## 设计原则
- **模块化**: 每个模块职责单一，高内聚低耦合
- **类型安全**: 全面使用TypeScript类型系统
- **可维护性**: 清晰的代码结构和命名规范
- **可扩展性**: 易于添加新功能和模块

## 导入规范
```typescript
// 相对路径导入
import { characterApi } from '@/api'
import { useCharacterStore } from '@/stores/character'
import type { Character } from '@/types'

// 组件导入
import MyComponent from '@/components/MyComponent.vue'
```

## 开发流程
1. 在types中定义数据类型
2. 在api中封装API调用
3. 在stores中管理状态
4. 在components中创建可复用组件
5. 在views中组合组件创建页面
6. 在router中配置路由

## 代码风格
- 使用Composition API
- 使用<script setup>语法糖
- 使用TypeScript类型注解
- 遵循Vue 3组合式函数最佳实践
