# Router - 路由配置

## 概述
管理应用的所有路由配置，包括路由定义、导航守卫等。

## 路由配置

### 路由列表
```typescript
/                          → 重定向到 /characters
/characters                → 角色管理页面
/characters/:id            → 角色详情页面
/dungeons                  → 副本管理页面
/bosses                    → Boss管理页面
/item-needs                → 装备需求管理页面
```

### 路由元信息
```typescript
{
  path: '/characters',
  name: 'Characters',
  component: CharactersView,
  meta: {
    title: '角色管理',           // 页面标题
    requiresAuth: false,        // 是否需要认证
    keepAlive: false            // 是否缓存
  }
}
```

## 路由守卫

### 全局前置守卫
```typescript
router.beforeEach((to, from, next) => {
  // 设置页面标题
  if (to.meta.title) {
    document.title = `${to.meta.title} - 魔兽世界角色管理系统`
  }

  // 认证检查（未来实现）
  // if (to.meta.requiresAuth && !isAuthenticated()) {
  //   next('/login')
  //   return
  // }

  next()
})
```

### 计划中的守卫
- **认证守卫**: 检查用户登录状态
- **权限守卫**: 检查用户访问权限
- **数据预加载**: 在路由切换前预加载数据

## 路由模式
- **模式**: createWebHistory (HTML5 History模式)
- **基础路径**: import.meta.env.BASE_URL
- **滚动行为**: 默认滚动到顶部

## 懒加载
所有页面组件都使用懒加载：
```typescript
component: () => import('@/views/CharactersView.vue')
```

## 路由参数
### 动态路由参数
```typescript
/characters/:id
// 访问: /characters/abc123
// 获取: route.params.id
```

### 查询参数
```typescript
/characters?filter=warrior
// 获取: route.query.filter
```

## 导航方法
```typescript
// 编程式导航
router.push('/characters')
router.push({ name: 'CharacterDetail', params: { id: '123' }})
router.replace('/characters')
router.go(-1)  // 后退

// 声明式导航
<router-link to="/characters">角色管理</router-link>
```

## 路由过渡
```vue
<router-view v-slot="{ Component }">
  <transition name="fade" mode="out-in">
    <component :is="Component" />
  </transition>
</router-view>
```

## 错误处理
- 404页面：未找到路由
- 500页面：服务器错误
- 加载状态：路由切换时的loading

## 扩展指南
添加新路由时：
1. 在views目录创建页面组件
2. 在路由配置中添加路由定义
3. 设置适当的meta信息
4. 考虑是否需要路由守卫
5. 更新导航菜单（如有需要）

## 最佳实践
- 使用命名路由便于维护
- 合理使用路由参数和查询参数
- 懒加载页面组件提升性能
- 为路由设置有意义的名称
- 在meta中存储路由相关的元数据
