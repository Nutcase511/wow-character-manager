# Stores - Pinia状态管理

## 概述
使用Pinia进行全局状态管理，替代Vuex提供更现代的状态管理方案。

## 核心Store

### characterStore (角色状态管理)
管理角色相关的状态和操作。

#### 状态
```typescript
characters: Character[]           // 所有角色列表
currentCharacter: Character | null // 当前选中角色
loading: boolean                  // 加载状态
error: string | null             // 错误信息
```

#### 计算属性
```typescript
characterCount: number           // 角色总数
hasCharacters: boolean           // 是否有角色
```

#### 方法
```typescript
fetchCharacters()                // 获取所有角色
fetchCharacter(id: string)       // 获取指定角色
createCharacter(data: CharacterCreate)  // 创建角色
updateCharacter(id: string, data: CharacterCreate)  // 更新角色
deleteCharacter(id: string)      // 删除角色
setCurrentCharacter(character: Character | null)  // 设置当前角色
```

### realmStore (服务器状态管理) (新增)
管理服务器相关的状态和操作，专门为时光服优化。

#### 状态
```typescript
realms: Realm[]                 // 所有服务器列表
classicRealms: Realm[]          // 怀旧服服务器列表
retailRealms: Realm[]          // 正式服服务器列表
loading: boolean                // 加载状态
error: string | null           // 错误信息
```

#### 计算属性
```typescript
realmCount: number              // 服务器总数
classicRealmCount: number       // 怀旧服服务器数
retailRealmCount: number       // 正式服服务器数
hasRealms: boolean             // 是否有服务器数据
```

#### 方法
```typescript
fetchRealms(params?)            // 获取服务器列表
fetchClassicRealms(region?)     // 获取怀旧服服务器列表
fetchRetailRealms(region?)      // 获取正式服服务器列表
fetchRealm(slug: string, classic: boolean)  // 获取指定服务器
searchRealms(query: string, realmList?)  // 搜索服务器
getRealmByName(name: string)    // 按名称获取服务器
getRealmBySlug(slug: string)    // 按slug获取服务器
getRealmsByRegion(region: string)  // 按区域获取服务器
getRealmsByCategory(category: string)  // 按分类获取服务器
```

### itemNeedStore (装备需求状态管理)
管理装备需求相关的状态和操作。

#### 状态
```typescript
itemNeeds: ItemNeed[]            // 所有装备需求
currentProgress: ItemProgress | null  // 当前进度统计
loading: boolean                 // 加载状态
error: string | null            // 错误信息
```

#### 计算属性
```typescript
totalNeeds: number               // 总需求数
obtainedNeeds: ItemNeed[]        // 已获取的装备
pendingNeeds: ItemNeed[]         // 未获取的装备
```

#### 方法
```typescript
fetchItemNeeds(params?)          // 获取装备需求列表
fetchItemNeed(id: string)        // 获取指定装备需求
createItemNeed(data: ItemNeedCreate)  // 创建装备需求
updateItemNeed(id: string, data: ItemNeedCreate)  // 更新装备需求
markAsObtained(id: string)       // 标记为已获取
deleteItemNeed(id: string)       // 删除装备需求
fetchProgress(characterId: string)  // 获取进度统计
filterByCharacter(characterId: string)  // 按角色过滤
filterByStatus(obtained: boolean)  // 按状态过滤
```

## Store设计模式

### Composition API风格
```typescript
export const useExampleStore = defineStore('example', () => {
  // 状态
  const count = ref(0)
  const name = ref('example')

  // 计算属性
  const doubleCount = computed(() => count.value * 2)

  // 方法
  function increment() {
    count.value++
  }

  return {
    count,
    name,
    doubleCount,
    increment
  }
})
```

## 状态持久化
计划集成状态持久化，使用pinia-plugin-persistedstate：
```typescript
// 持久化配置
persist: {
  key: 'character-store',
  storage: localStorage,
  paths: ['characters']  // 只持久化特定状态
}
```

## 最佳实践

### 状态设计
- 保持状态扁平化，避免深层嵌套
- 只存储必要的状态，派生数据使用计算属性
- 合理划分状态职责

### 异步操作
- 所有异步操作都要有loading状态
- 统一的错误处理机制
- 适当的用户反馈

### 类型安全
- 为Store定义完整的TypeScript类型
- 使用泛型确保类型正确
- 避免any类型

## 使用示例
```typescript
import { useCharacterStore } from '@/stores/character'

// 在组件中使用
const characterStore = useCharacterStore()

// 访问状态
console.log(characterStore.characters)
console.log(characterStore.loading)

// 调用方法
await characterStore.fetchCharacters()
await characterStore.createCharacter({
  name: 'Player1',
  realm: 'Stormrage',
  wow_class: 'warrior',
  level: 70
})

// 监听状态变化
watch(() => characterStore.loading, (newVal) => {
  console.log('Loading状态变化:', newVal)
})
```

## 计划中的Store
- **userStore** - 用户认证和权限管理
- **uiStore** - UI状态（主题、布局等）
- **cacheStore** - 数据缓存管理
- **notificationStore** - 通知和消息管理
