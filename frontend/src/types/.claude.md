## 类型使用指南

### 基础使用
```typescript
import type { Character, CharacterCreate } from '@/types'

const character: Character = {
  id: '123',
  name: 'Player1',
  realm: 'Stormrage',
  wow_class: 'warrior',
  level: 70,
  faction: 'alliance',
  created_at: '2024-01-01',
  updated_at: '2024-01-01'
}

const newCharacter: CharacterCreate = {
  name: 'Player2',
  realm: 'Stormrage',
  wow_class: WoWClass.PALADIN,
  level: 70,
  faction: 'alliance'
}
```

### 类型守卫
```typescript
function isCharacter(obj: any): obj is Character {
  return obj &&
    typeof obj.id === 'string' &&
    typeof obj.name === 'string' &&
    typeof obj.wow_class === 'string'
}
```

### 类型推断
```typescript
function processCharacter(character: Character) {
  // TypeScript会自动推断character的类型
  console.log(character.name.toUpperCase())
}
```

## 扩展指南
添加新类型时：
1. 确定类型用途和复用性
2. 选择合适的类型定义方式（interface/type）
3. 为复杂类型添加注释说明
4. 考虑类型之间的继承关系
5. 保持类型定义的一致性

## 最佳实践
- 优先使用interface定义对象类型
- 使用type定义联合类型、交叉类型
- 为泛型类型提供合理的默认值
- 避免使用any类型，使用unknown代替
- 为复杂类型添加JSDoc注释
- 保持类型定义的DRY原则
