# Assets - 静态资源

## 概述
存放应用的静态资源文件，包括图片、样式、字体等。

## 资源类型

### 图片资源
- **位置**: `assets/images/`
- **格式**: 支持常见图片格式（jpg, png, svg, webp）
- **用途**: Logo、图标、背景图等

### 样式资源
- **位置**: `assets/styles/`
- **格式**: CSS, SCSS, LESS
- **用途**: 全局样式、主题变量、重置样式等

### 字体资源
- **位置**: `assets/fonts/`
- **格式**: woff, woff2, ttf
- **用途**: 自定义字体文件

### 图标资源
- **位置**: `assets/icons/`
- **格式**: SVG图标
- **用途**: 自定义SVG图标

## 资源组织

### 推荐目录结构
```
assets/
├── images/
│   ├── logo/           # Logo相关图片
│   ├── icons/          # 图标图片
│   ├── backgrounds/    # 背景图片
│   └── avatars/        # 头像图片
├── styles/
│   ├── variables.scss  # 样式变量
│   ├── mixins.scss     # 样式混入
│   ├── common.scss     # 通用样式
│   └── themes/         # 主题样式
├── fonts/              # 字体文件
└── icons/              # SVG图标
```

## 资源引用

### 在Vue组件中引用
```vue
<template>
  <img :src="logoUrl" alt="Logo">
</template>

<script setup lang="ts">
import logoUrl from '@/assets/images/logo.png'
</script>
```

### 在样式文件中引用
```scss
@import '@/assets/styles/variables.scss';

.hero {
  background-image: url('@/assets/images/backgrounds/hero.jpg');
  background-size: cover;
}
```

### 在TypeScript中引用
```typescript
import iconUrl from '@/assets/icons/example.svg'

const icon = iconUrl
```

## 图片优化

### 格式选择
- **照片类**: 使用WebP格式（兼容性允许时）
- **图标类**: 使用SVG格式
- **透明背景**: 使用PNG格式
- **简单图形**: 使用SVG或PNG

### 尺寸规范
- 提供多种尺寸以适应不同设备
- 使用响应式图片技术
- 避免使用过大的图片

### 压缩建议
- 使用工具压缩图片文件大小
- 保持合理的视觉质量
- 考虑使用CDN加速

## 字体管理

### 字体引入
```scss
@font-face {
  font-family: 'CustomFont';
  src: url('@/assets/fonts/custom-font.woff2') format('woff2'),
       url('@/assets/fonts/custom-font.woff') format('woff');
  font-weight: normal;
  font-style: normal;
  font-display: swap;
}
```

### 字体使用
```scss
body {
  font-family: 'CustomFont', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
}
```

## 图标管理

### SVG图标组件
```vue
<template>
  <svg :class="className" :width="size" :height="size" viewBox="0 0 24 24">
    <path :d="iconPath" />
  </svg>
</template>

<script setup lang="ts">
import { computed } from 'vue'

interface Props {
  name: string
  size?: number | string
  className?: string
}

const props = withDefaults(defineProps<Props>(), {
  size: 24,
  className: ''
})

// 图标路径映射
const icons: Record<string, string> = {
  'example-icon': 'M12 2L2 7l10 5 10-5-10-5zm0 9l2.5-1.25L12 8.5l-2.5 1.25L12 11zm0 2.5l-5-2.5-5 2.5L12 22l10-8.5-5-2.5-5 2.5z'
}

const iconPath = computed(() => icons[props.name] || '')
</script>
```

## 性能优化

### 图片懒加载
```vue
<img :src="placeholder" :data-src="imageUrl" loading="lazy" alt="描述">
```

### 资源预加载
```html
<link rel="preload" href="/font.woff2" as="font" type="font/woff2" crossorigin>
<link rel="preload" href="/critical.css" as="style">
```

### 代码分割
```typescript
// 懒加载大图片
const loadHeavyImage = () => import('@/assets/images/heavy.jpg')
```
