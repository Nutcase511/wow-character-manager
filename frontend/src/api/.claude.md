# API - API调用层

## 概述
封装所有后端API调用，提供类型安全的HTTP请求方法。

## 核心模块

### axios实例
- **基础URL**: /api (通过Vite代理到localhost:8000)
- **超时时间**: 10秒
- **拦截器**: 请求/响应拦截器

## API模块

### characterApi (角色API)
```typescript
getAll()                           // 获取所有角色
getById(id: string)                // 获取指定角色
create(data: CharacterCreate)      // 创建角色
update(id: string, data: CharacterCreate)  // 更新角色
delete(id: string)                 // 删除角色
```

### itemNeedApi (装备需求API)
```typescript
getAll(params?: { character_id?: string; obtained?: boolean })
getById(id: string)
create(data: ItemNeedCreate)
update(id: string, data: ItemNeedCreate)
markObtained(id: string)           // 标记为已获取
delete(id: string)
getProgress(characterId: string)   // 获取进度统计
```

### dungeonApi (副本API)
```typescript
getAll()
getById(id: string)
create(data: Partial<Dungeon>)
syncFromBlizzard(journalInstanceId: number)  // 从暴雪API同步
delete(id: string)
```

### bossApi (Boss API)
```typescript
getAll(params?: { dungeon_id?: number })
getById(id: string)
create(data: Partial<Boss>)
syncFromBlizzard(journalEncounterId: number)  // 从暴雪API同步
getByDungeon(dungeonId: number)
delete(id: string)
```

### realmApi (服务器 API) (新增)
```typescript
getAll(params?: { classic?: boolean; region?: string })
getById(slug: string, params?: { classic?: boolean })
getClassicRealms(params?: { region?: string })  // 获取怀旧服服务器
getRetailRealms(params?: { region?: string })   // 获取正式服服务器
```

## 使用示例
```typescript
import { characterApi } from '@/api'

// 获取所有角色
const response = await characterApi.getAll()
const characters = response.data

// 创建角色
const newCharacter = await characterApi.create({
  name: 'Player1',
  realm: 'Stormrage',
  wow_class: 'warrior',
  level: 70
})

// 错误处理
try {
  await characterApi.delete(id)
} catch (error) {
  console.error('删除失败', error)
}
```

## 扩展指南
添加新API端点时：
1. 在types中定义请求/响应类型
2. 在对应的API模块中添加方法
3. 添加完整的类型注解
4. 实现适当的错误处理
5. 在store或组件中调用

## 最佳实践
- 使用async/await语法
- 始终处理可能的错误
- 利用TypeScript类型检查
- 避免在组件中直接调用axios
- 通过API模块封装所有HTTP请求
