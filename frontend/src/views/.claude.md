# Views - 页面组件

## 概述
包含应用的所有页面级组件，每个组件对应一个路由。

## 页面列表

### CharactersView (角色管理页面)
**路由**: `/characters`
**功能**:
- 显示所有角色列表
- 添加新角色
- 编辑角色信息
- 删除角色
- 点击角色卡片跳转到详情页

**组件特性**:
- 响应式网格布局
- 角色卡片展示
- 模态对话框表单
- 职业标签颜色区分
- 阵营标识（联盟/部落）

### CharacterDetailView (角色详情页面)
**路由**: `/characters/:id`
**功能**:
- 显示角色详细信息
- 装备获取进度统计
- 装备需求列表管理
- 添加/编辑/删除装备需求
- 标记装备为已获取

**组件特性**:
- 角色基本信息展示
- 进度条可视化
- 装备需求表格
- 状态过滤器（全部/未获取/已获取）
- 优先级星级评分

### DungeonsView (副本管理页面)
**路由**: `/dungeons`
**功能**:
- 显示所有副本列表
- 手动添加副本
- 从暴雪API同步副本数据
- 编辑/删除副本信息

**组件特性**:
- 副本信息表格展示
- 难度标签显示
- 暴雪API同步功能
- Journal ID输入验证

### BossesView (Boss管理页面)
**路由**: `/bosses`
**功能**:
- 显示所有Boss列表
- 手动添加Boss
- 从暴雪API同步Boss数据
- 编辑/删除Boss信息

**组件特性**:
- Boss信息表格展示
- 所属副本显示
- 暴雪API同步功能
- Journal Encounter ID输入验证

### ItemNeedsView (装备需求管理页面)
**路由**: `/item-needs`
**功能**:
- 显示所有装备需求
- 按角色过滤需求
- 按状态过滤需求
- 添加/编辑/删除装备需求
- 标记装备为已获取

**组件特性**:
- 角色选择器
- 状态过滤器
- 装备需求表格
- 优先级显示
- 批量操作支持

## 页面组件结构

### 标准页面模板
```vue
<template>
  <div class="page-view">
    <!-- 页面头部 -->
    <div class="page-header">
      <h2 class="page-title">页面标题</h2>
      <div class="header-actions">
        <!-- 操作按钮 -->
      </div>
    </div>

    <!-- 页面内容 -->
    <el-card class="page-content">
      <!-- 主要内容区域 -->
    </el-card>

    <!-- 对话框等弹窗组件 -->
    <el-dialog v-model="showDialog">
      <!-- 对话框内容 -->
    </el-dialog>
  </div>
</template>

<script setup lang="ts">
import { ref, onMounted } from 'vue'
import { useRouter } from 'vue-router'

// 路由
const router = useRouter()

// 响应式数据
const loading = ref(false)
const showDialog = ref(false)

// 生命周期
onMounted(() => {
  // 初始化数据
})

// 方法
function handleClick() {
  // 处理点击事件
}
</script>

<style scoped>
.page-view {
  /* 页面样式 */
}
</style>
```

## 页面设计原则

### 用户体验
- 清晰的页面标题和操作指引
- 合理的信息层次结构
- 友好的错误提示和加载状态
- 响应式设计适配不同屏幕

### 性能优化
- 懒加载页面组件
- 合理使用v-if和v-show
- 列表虚拟滚动（大数据量）
- 图片懒加载

### 可维护性
- 组件职责单一
- 逻辑清晰，注释完善
- 遵循Vue 3最佳实践
- TypeScript类型安全

## 扩展指南
创建新页面时：
1. 在router中配置路由
2. 创建页面组件文件
3. 实现页面逻辑和模板
4. 添加页面样式
5. 更新导航菜单（如有需要）
6. 测试页面功能
